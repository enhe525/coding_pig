# Coding Pig · 抽签器

一个用 Python 写的 Windows 抽签小工具。

## 文件说明

- `抽签.py`：主程序，从 `draws.txt` 中随机抽取签
- `放签辅助.py`：辅助程序，向 `draws.txt` 添加新签
- `draws.txt`：签文数据文件，每行一个签

## 使用方法

1. 确保已安装 Python 3（仅使用标准库，无需额外安装依赖）
2. 把所有文件放在同一个文件夹里
3. 运行主程序：
   ```
   python 抽签.py
   ```
4. 想添加新签时运行：
   ```
   python 放签辅助.py
   ```

## 说明

- 抽签为**不放回抽样**：一次抽多个签时不会重复命中。
- 数据文件 `draws.txt` 每行一个签，支持中文，UTF-8 编码。
- 彩蛋：如果你以 `NT AUTHORITY\SYSTEM` 身份运行本程序，会看到一段温馨提示 :)
